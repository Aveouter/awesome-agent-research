# Research Idea Backlog

只有能明确写出假设、实验和反证条件的想法才进入这里。

## IDEA-001：元认知驱动的自适应多 Agent 路由

- 状态：待验证
- 问题：固定多 Agent 工作流是否在简单任务上浪费成本，并在困难任务上调用错误的专家？
- 假设：基于任务难度、Agent 能力画像和置信度的动态路由，可以在相同 Token 预算下超过固定拓扑和 best-of-N。
- 最小实验：在编码或通用 Agent benchmark 上比较单 Agent、best-of-N、固定星形、固定网状和动态路由。
- 指标：任务成功率、Token、延迟、校准误差、各类失败率。
- 反证条件：控制模型和 Token 后，动态路由没有稳定提升，或提升完全来自更多推理预算。
- 相关论文：MA-001、MA-002、MC-001。

## IDEA-002：基于失败类型的经验记忆

- 状态：待验证
- 问题：把全部历史轨迹放入上下文会引入噪声，怎样决定记住什么？
- 假设：按失败类型和可迁移技能筛选记忆，比相似度检索或最近邻回放更有效且更节省上下文。
- 最小实验：在 LifelongAgentBench 的一个环境中比较无记忆、最近轨迹、语义检索、失败感知检索。
- 指标：连续任务成功率、遗忘程度、上下文长度、检索命中率。
- 反证条件：性能主要由示例数量决定，失败标签没有提供额外增益。
- 相关论文：CL-002、MA-001。
