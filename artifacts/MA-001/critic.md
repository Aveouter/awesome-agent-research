## 1. Claim—机制—证据链

标签帮助发现工作流问题 → 修改验证/角色/终止机制 → 观察任务表现变化。前两者与结果之间还存在额外预算等混杂，不能从分类相关性直接推出根因。

## 2. 核心审稿质疑

- C1：收益来自机制还是额外推理？对象为表 5；同模型干预的结果是作者直接报告，预算混杂风险为个人推断。影响：决定其是否能支持成本受限路由。
- C2：标签何时可获得？对象为完整轨迹标注；原文此处没有在线前缀路由试验。个人推断：事后可解释性不保证提前可干预性。
- C3：标签是否等于根因？§3 的一致性支持可重复描述；个人推断：一致标注不能排除多个原因导致同一表征。

## 3. Baseline、消融与评价问题

预算匹配对照缺失；GPT-4 的新拓扑结果与一般性“拓扑更好”表述需分开。ChatDev 小题组的误差估计不足，不能据单表承诺普遍改善。

## 4. 泛化、鲁棒性、效率与复现问题

跨系统轨迹难度与目标不同，禁止用失败计数直接排名。标注器成本与执行成本分开；数据命名及版本需在实现前核对。

## 5. 最值得验证的问题

| 优先级 | 问题 | 重要性 | 可验证性 | 预计成本 |
|---|---|---|---|---|
| P0 / C1 | 控制预算后 prompt 干预是否有效 | 决定后续方向 | 同题配对可验证 | 先小样本 API 预跑，金额待测 |
| P1 / C2 | 轨迹前缀能否预测干预收益 | 决定在线价值 | 需另采前缀与反事实分支 | 高于首轮 |

## 6. 潜在研究空缺

个人推断：可干预收益预测比只预测失败更贴合路由决策；这不是经过竞争工作检索确认的创新性主张。

## 7. 当前材料不足以确认的事项

原代码复现性、具体 Token 差异、置信区间、当前模型可用性均未验证。没有证据证明某类标签已经具有因果解释。
