### 4. 批判性判断（个人推断）

- 分类维度不是天然正交：角色会影响通信对象，环境决定反馈可得性；实验同时改角色与拓扑会让归因困难。
- “记忆检索”“自我调整”是行为机制，不自动满足本仓库的持续学习定义。需另测跨任务收益、遗忘和预算。
- 世界模拟关注行为逼真度，问题求解关注任务正确性，两类评价不能汇成统一成功率。
- 综述不能回答“何时值得多 Agent”。这个判断需要强单 Agent、等预算独立采样和任务级配对结果。

本篇为综述，不开展数值复现。最小验证是选一个准备使用的系统，按四维填写配置，并标记每项证据来源及未知项；无需模型调用。完整引用筛选流程本次未逐项审阅，不能声明已审计综述覆盖完整性。
